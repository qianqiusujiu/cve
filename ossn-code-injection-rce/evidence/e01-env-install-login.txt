### Installation (OSSN wizard, steps driven by HTTP)
1. GET  /installation/?page=license   -> 200
2. POST /installation/?action=install (dbuser=root, dbhost=127.0.0.1:3308, dbname=ossn, url=http://127.0.0.1:8093/, datadir=<tmp>/ossn-data-8093/, owner_email/notification_email/sitename set) -> 302 ?page=account (success)
3. POST /installation/?action=account (username=admin, type=admin, validated) -> 302 ?page=installed
   DB check: SELECT guid,username,type FROM ossn_users => 1 | admin | admin
4. POST /installation/?action=finish -> 302 /administrator ; INSTALLED marker file created

- Proof of authenticated admin session:

### Note on action dispatch
- Production canonical URL /action/<name> is a .htaccess rewrite of system/handlers/actions.php?action=<name> (RewriteRule ^action/([A-Za-z0-9\_\-\/]+)$ system/handlers/actions.php?action=$1). Under php -S the un-rewritten path was used; identical code path (ossn_action(input('action'))).
