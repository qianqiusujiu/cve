MARKER ANALYSIS
---------------
* Fatal at class.FlickrAPIAccessor.php:62 ($fphoto['stat']) proves unserialize() at
  line 60 returned a fully instantiated attacker-chosen PostIterator object built
  from the network response body (marker 1: object injection confirmed).
* "Next Error: Call to undefined method stdClass::closeCursor()" raised from
  PostIterator->__destruct() (declared line 124, sink line 127) proves the
  destructor POP entry fires on attacker-controlled data during request shutdown
  (marker 2). In the real application the same unserialize() runs inside the
  crawler process where ThinkUp's autoloader exposes its full class set,
  including PostIterator (used by the crawler itself to iterate posts).
* The error-based marker is harmless: no file writes, no command execution,
  process exit 255 only.
